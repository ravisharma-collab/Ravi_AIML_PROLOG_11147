AIML Prolog Facts
📌 About

This repository contains basic programs and examples of Prolog facts for Artificial Intelligence and Machine Learning (AIML). It demonstrates how to represent knowledge and relationships using facts, predicates, and logical queries in Prolog.

🎯 Objectives
Understand the basics of Prolog programming.
Learn how to define facts and predicates.
Represent knowledge using logical relationships.
Execute queries to retrieve information from a knowledge base.
🧠 Topics Covered
Prolog facts
Predicates and queries
Knowledge representation
Logical reasoning
Introduction to rule-based programming
🛠️ Requirements
SWI-Prolog or another compatible Prolog interpreter.
🚀 How to Run
Clone this repository:
git clone <repository-url>

Navigate to the project directory:
cd <repository-folder>

Open the .pl file in SWI-Prolog.
Load the file:
[filename].

Run queries in the Prolog console.
💡 Example
% Facts
parent(john, mary).
parent(mary, alice).

% Query
% ?- parent(john, mary).
% Output: true.

By exploring this repository, you will gain a basic understanding of Prolog facts, knowledge representation, and logic-based problem-solving in AI.
